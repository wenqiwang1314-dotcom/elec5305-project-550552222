# Canvas submission draft

This project investigates resource-aware keyword spotting for ten spoken
commands, unknown speech, and silence using MATLAB and Speech Commands v0.02.
The current GitHub Project Site documents the proposed MFCC and DSCNN workflow,
the speaker-disjoint evaluation design, references, timeline, and a preliminary
real-data baseline. The first reproducible smoke test reached 39.17% accuracy on
240 held-out samples with zero audited speaker overlap; its main failure,
unknown-word rejection, defines the next research stage.
