Ten archives contain target commands. The _unknown_ archive samples other Speech Commands labels, while _silence_ contains deterministic one-second windows derived from the upstream background-noise recordings at 10% amplitude. The train/test assignment is fixed by the project manifest and has zero audited speaker overlap.

Integrity: all 12 ZIP CRCs, all 960 manifest hashes, all audio format checks, and all 880 source-copy byte comparisons pass. Every WAV is mono at 16 kHz; 876 files contain 16,000 samples and 84 are shorter (minimum 7,509 samples). The fixed-clip adapter right-pads short recordings with zeros before producing the 49 × 10 input. Source WAVs remain byte-for-byte copies.

Scope and attribution

The upstream data are Google Speech Commands v0.02 by Pete Warden, distributed under CC BY 4.0. Please cite Speech Commands: A Dataset for Limited-Vocabulary Speech Recognition.

This 960-file package is intended for quick, reproducible diagnostics and continuous checks. It is not a replacement for full-corpus multi-seed model training. The complete local corpus contains 105,829 WAV files (about 3.34 GB) and remains outside ordinary Git history.
